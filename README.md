# cli-task-manager

Un utilitaire open-source léger en ligne de commande (CLI) permettant aux développeurs de gérer leurs tâches et leurs sprints directement depuis leur terminal.

## 🚀 Fonctionnalités

- **Rapide et léger :** Aucune interface lourde, fonctionne directement dans votre terminal.
- **Hors-ligne :** Vos tâches sont sauvegardées localement au format JSON.
- **Simple d'utilisation :** Commandes intuitives pour ajouter, lister et terminer vos tâches.

## 📦 Installation

Clonez le dépôt sur votre machine locale :

```bash
git clone https://github.com
cd cli-task-manager
```

## 💻 Utilisation

```bash
# Ajouter une nouvelle tâche
python task.py add "Corriger le bug de connexion"

# Afficher toutes les tâches
python task.py list

# Marquer une tâche comme terminée
python task.py done 1
```
